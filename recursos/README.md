# Recursos adaptados que entram no LowMine

Os arquivos de origem utilizados pelo construtor são armazenados em fontes_adaptadas.zlib.b64 como um conjunto JSON comprimido e versionado.

Esse conjunto contém apenas:
- 14 definições de partículas adaptadas de FPS Optimizer v2.9.2, com o namespace lowmine:.
- water/water.json, com cáusticas e ondas desativadas.
- shadows/global.json, com sombras blocadas.

PotatoCraft, Embeddium Optimizer e Vanilla × Optimizer foram estudados apenas como referências; nenhum arquivo desses pacotes foi copiado.
