# Recursos adaptados que entram no LowMine

O arquivo `fontes_adaptadas.zlib.b64` contém um JSON compactado e versionado com 16 recursos selecionados do FPS Optimizer v2.9.2:
- 14 definições de partículas.
- `water/water.json`, com cáusticas e ondas desativadas.
- `shadows/global.json`, com sombras blocadas.

Autor original: XiaoCraft. Licença: CC BY-NC 3.0. O construtor converte o namespace de configuração original para `lowmine:`, define 50% de partículas e limite 6 como padrão e mantém os créditos no pacote.

PotatoCraft, Embeddium Optimizer e Vanilla × Optimizer foram estudados apenas como referências; nenhum arquivo desses três pacotes foi copiado. Consulte [CREDITOS.md](../CREDITOS.md) para autoria, alterações e condições de licença.
