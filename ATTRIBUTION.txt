Changes made by the LowMine Project in v0.3.2:
  - Removed the PvP subpack and kept the former Lite profile as the only profile.
  - Corrected manifest v3 version fields to SemVer strings after the v0.3.0 import failure.
  - Removed experimental custom pack settings and their Molang queries.
  - Set all included particle emitter maximums and spawn counts to zero.
  - Disabled XP-orb drawing without changing the game's XP collection behavior.
  - Kept translucent desktop/pocket inventory and chest UI, hotbar/touch edits and short visual fog.

This is an adaptation, not an original replacement for the source work. No measured FPS improvement is claimed. Runtime testing is required.
